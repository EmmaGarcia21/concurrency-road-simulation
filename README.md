
# Concurrent Road Simulation

Implementation of a concurrent road traffic management system using different synchronization approaches.

## Features
- Road representation using segments and lanes.
- Vehicle entry, movement and exit management.
- Shared resource synchronization.
- Monitor-based concurrency control.
- CSP-based communication using JCSP channels.
- Coordination of concurrent vehicle operations.

## Technologies
- Java
- Concurrency
- Monitors
- CSP
- JCSP
- Synchronization
- Concurrent Programming

Developed as part of my Computer Science Engineering studies at UPM.
